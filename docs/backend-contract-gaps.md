Places where `contracts/openapi.json` (first vendored at backend `920ff6a`, 2026-10-22; last
synced at `30f5873`, 2026-11-09) and the documents disagree, found from the client
side. This repository never modifies `../moyi-backend`;
each gap is written here for a backend session to fix, together with how the client copes
until then. Checked with `jq` against the contract, not only read.
